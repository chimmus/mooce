# mooce

mooce is designed to be a list. You can add stuff to it and get random things back.
There are many use cases.

# Building
Clone the git repo.
```bash
git clone https://github.com/chimmus/mooce.git ~/mooce
```
Next build the program with `cargo`:
```bash
cd ~/mooce
cargo build --release
cargo install --path .
```
